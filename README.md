# Le Parad’Ysi

Site vitrine statique de présentation, réalisé pour Ysidia à Peyruis.

## Adresse temporaire

https://propulsite1179.github.io/le-paradysi/

Les pages comportent des consignes de non-indexation pendant la validation. L’aperçu est public et reste accessible sans connexion.

## Publication

GitHub Pages sert la racine de la branche `main`. Aucun outil de compilation, compte client ou abonnement supplémentaire n’est requis.

Le formulaire prépare un SMS localement ; la personne choisit ensuite l’envoi dans son application SMS. Un rendez-vous doit être confirmé directement avec Ysidia.

## Contenus

Seuls le logo et trois photographies de l’espace ont été intégrés. Aucune conversation, photographie de cliente, comparaison avant/après ou pièce privée n’est incluse.

Les images et l’identité de l’établissement restent la propriété de leurs ayants droit. Les licences des polices auto-hébergées se trouvent dans `assets/fonts/`.

Les tarifs actuels et les informations complètes d’édition doivent être validés avant l’ouverture sur le domaine définitif.
